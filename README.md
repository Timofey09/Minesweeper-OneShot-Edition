### This is a fan-made non-commercial project.

## How to install:
1. Download from Releases page,
2. Unzip all files to a easy-accessible folder on your PC,
3. Open folder with game,
4. Launch "Minesweeper.exe".

## System requrements:
- Windows 7 or newer (8, 10, 11),
- 512 MB RAM and more.
- .NET 4.7.2 (will be offered to download if not)

### Currently only on Russian. English and other language localization in future releases
